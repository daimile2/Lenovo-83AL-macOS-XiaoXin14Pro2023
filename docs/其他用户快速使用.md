# 其他用户快速使用：Windows／Linux 一步制作 macOS 安装 U 盘

> [!CAUTION]
> **数据无价，看好分区再分盘安装；分盘操作不能反悔，且分完盘数据丢失在软件上不可能找回（作者个人经历）。**

## 你实际得到什么

脚本会从仓库中的 `EFI/OC/` 开始，一次完成：

1. 生成你自己的 `SystemSerialNumber`、MLB、SystemUUID 和 ROM，只写入临时副本。
2. 建立 4 GiB FAT32 GPT 启动分区，默认 `EFI/Boot/BOOTX64.EFI` 直接指向 OpenCore。
3. 使用 Acidanthera OpenCorePkg 1.0.8 官方 `macrecovery.py`，从 Apple 下载并校验 MacBookPro16,2 最新 Recovery。
4. 把 `BaseSystem.dmg`、`BaseSystem.chunklist` 和纯 OpenCore 写入 U 盘。
5. 可选把同一套 OpenCore 安装到内部 ESP，并备份原 `OC` 与默认启动文件。

**公开部署不包含发布者的 `EFI/ubuntu`、rEFInd、主题、磁盘 GUID 或个人启动项。** 只制作 U 盘时不会询问内部 ESP；只有选择写入内部 ESP 时才需要选择系统分区。

这是 **Apple Recovery 联网安装盘**：制作时下载 Recovery，进入 Recovery 后安装完整 macOS 时仍需联网。它不是全量离线安装镜像。

## 准备

- 只适用于 Lenovo 83AL／小新 Pro 14 2023 IRH8 的对应硬件组合。
- 8 GB 或更大的 U 盘；U 盘会被完全擦除。
- 可用网络。
- Windows 需要 Python 3；Linux 需要 x86-64 Python 3、util-linux、parted 和 dosfstools。

## Windows

在仓库根目录打开**管理员 PowerShell**：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Tools\Windows\Lenovo83AL-EFI工具.ps1
```

选择：

```text
1 = 制作 macOS 安装 U 盘
2 = 只安装 OpenCore 到内部 ESP
3 = 两者都做
```

制作 U 盘时选择整个 USB 磁盘编号，再输入 `ERASE 编号` 才会擦除。脚本随后自动下载并校验 Apple Recovery，不需要手工寻找镜像或建立目录。

## Linux

```bash
sudo bash Tools/Linux/Lenovo83AL-EFI工具.sh
```

U 盘必须输入整盘设备，例如 `/dev/sdb`，不能输入 `/dev/sdb1`，并输入 `ERASE` 确认。缺少工具时，在 Debian／Ubuntu 可安装：

```bash
sudo apt install python3 util-linux parted dosfstools
```

## 启动并安装 macOS

1. 通过开机启动菜单选择 `L83INSTALL` U 盘。
2. 在 OpenCore 中进入 Recovery。
3. 再次核对目标磁盘和分区，然后使用磁盘工具与安装器。
4. 保持网络连接，等待完整 macOS 下载与安装。

目标环境为 macOS 26.7.3（25G342）。Apple 的 `latest` Recovery 由苹果服务器决定；如果实际安装出的 build 不是 `25G342`，不要直接运行仅针对该 build 核对的主机端安装器。

## 安装完成后必须执行

在仓库根目录运行：

```bash
bash Tools/安装主机端组件.sh
```

该步骤安装 NullMoth 主机端显示与 Metal 组件、GSP 固件和双麦 HAL，并在当前 Mac 上重建 AuxKC。Windows／Linux 脚本不能替代这一步。

## 内部 ESP 与隐私

- 内部写入只替换 `EFI/OC` 和默认 `EFI/Boot/BOOTX64.EFI`，不会把发布者的其他启动目录复制给其他用户。
- 原 `OC` 和默认启动文件会先备份；脚本不自动修改固件 NVRAM 启动项。
- 不要把生成后的个人 `config.plist` 再提交到公开仓库。

## 当前验证边界

Linux 脚本通过 Bash 语法检查，官方 Linux macserial 已核对参数与输出格式；macrecovery 使用官方原始源码。Windows PowerShell 脚本完成静态复核，但尚未在真实 Windows 环境执行。实际下载、磁盘擦写和不同厂商固件启动结果仍需同机型用户验收。
